1. Por que acontece

O RADAR JUDICIAL é um programa pequeno, instalado na pasta C:\LexSuiteONE, que lê fontes públicas da Justiça e grava a relação de processos numa planilha do escritório. Para funcionar sem ninguém abrir a tela, ele cria uma tarefa no Agendador de Tarefas do Windows (chamada LexSuiteONE Radar) e roda pelo Python portátil que vem junto.

Alguns antivírus tratam esses passos como suspeitos: um instalador em .bat que baixa arquivos, um programa que cria tarefa agendada, um executável sem assinatura digital conhecida. É um falso positivo: o programa não é malicioso, mas se parece com um padrão que o antivírus vigia. Os sinais mais comuns são "comportamento malicioso", o instalador apagado logo depois de baixado, ou a mensagem "Não consegui criar a leitura automática" ao salvar a Rotina de leitura.

O que o programa faz e não faz. O código é público (publicado no GitHub) e as atualizações são assinadas pela SolverONE; o programa não acessa áreas logadas, não envia a planilha nem os dados do escritório a ninguém e não instala nada fora da própria pasta. Se preferir não liberar nada no antivírus, use o pacote completo, que não baixa arquivos durante a instalação; a leitura automática ainda precisará da tarefa agendada.

2. O que liberar

Em quase todo antivírus há duas listas diferentes: a de pastas e arquivos que a proteção em tempo real deixa passar e a de programas que a proteção por comportamento deixa rodar. Para o RADAR JUDICIAL funcionar inteiro, libere nos dois lugares:

A pastaC:\LexSuiteONE
com as subpastas. Em instalações antigas pode ser %LOCALAPPDATA%\LexSuiteONE.
Os programasC:\LexSuiteONE\python\pythonw.exe
C:\LexSuiteONE\python\python.exe
o primeiro roda a leitura automática sem janela; o segundo, a tela e o instalador.

Se o antivírus perguntar na hora ("permitir este programa?"), permitir ali já resolve na maioria dos casos. Se ele tiver apagado o instalador ou colocado algo em quarentena, restaure o item e depois adicione a exceção. Em cada seção abaixo há o caminho da quarentena.

4. Passo a passo por antivírus

Os caminhos de menu estão como a documentação do fabricante escreve (quase sempre em inglês; a versão em português do programa usa os termos equivalentes). As telas mudam de uma versão para outra: se o seu antivírus não bater com o texto, procure "exclusões", "exceções" ou "lista de permitidos" nas configurações, ou abra a página oficial indicada. A marca fonte lida quer dizer que lemos a página oficial inteira; confirmar quer dizer que só vimos o resumo da página oficial ou que o passo veio da comunidade do fabricante, e vale conferir na tela antes de confiar.

1. Why it happens

RADAR JUDICIAL is a small program installed in C:\LexSuiteONE. It reads public court sources and writes the list of lawsuits to the firm's spreadsheet. To run without anyone opening the window, it creates a task in Windows Task Scheduler (named LexSuiteONE Radar) and runs on the portable Python that ships with it.

Some antivirus products treat those steps as suspicious: a .bat installer that downloads files, a program that creates a scheduled task, an executable without a well-known digital signature. It is a false positive: the program is not malicious, but it resembles a pattern the antivirus watches. The usual signs are "malicious behavior", the installer deleted right after download, or the message "Could not create the automatic reading" when saving the reading schedule.

What the program does and does not do. The code is public (published on GitHub) and updates are signed by SolverONE; the program does not access logged-in areas, does not send the spreadsheet or the firm's data to anyone and installs nothing outside its own folder. If you prefer not to allow anything in the antivirus, use the complete package, which downloads nothing during installation; automatic reading will still need the scheduled task.

2. What to allow

Almost every antivirus has two different lists: folders and files that real-time protection lets through, and programs that behavior protection lets run. For RADAR JUDICIAL to work fully, allow it in both:

The folderC:\LexSuiteONE
with subfolders. Older installations may use %LOCALAPPDATA%\LexSuiteONE.
The programsC:\LexSuiteONE\python\pythonw.exe
C:\LexSuiteONE\python\python.exe
the first runs the automatic reading without a window; the second runs the screen and the installer.

If the antivirus asks at the moment ("allow this program?"), allowing it there solves most cases. If it deleted the installer or quarantined something, restore the item and then add the exception. Each section below gives the quarantine path.

Menu paths are written as the vendor's documentation writes them. Microsoft Defender (Windows 10 and 11) source read

Repeat with Process for C:\LexSuiteONE\python\pythonw.exe and python.exe (Microsoft recommends the full path to the executable). A folder exclusion covers everything inside it.
